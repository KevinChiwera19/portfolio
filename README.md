# Kevin Chiwera — Portfolio

Responsive static portfolio and interactive project demos, ready for GitHub Pages.

## Files

- `index.html` — portfolio home page.
- `styles.css` and `main.js` — site styles and navigation behavior.
- `projects/` — individual case studies for Nova Insurance, V2G, and OpsDesk.
- `assets/` — portrait, project screenshots, and favicon.
- `opsdesk/` — AI-assisted fictional IT operations demo. Its workflows and records are simulated and do not connect to company systems.

## Publish with GitHub Pages

1. Create a public GitHub repository for the portfolio.
2. Upload the **contents** of this folder to the repository root (the `index.html` file should be at the root).
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. GitHub Pages will show the published URL in the same settings section.

Keep the folder structure intact when uploading. The project demos already link to their published websites and source repositories. The OpsDesk demo stores sample state in the visitor's browser only; never add real company details, user data, or credentials.
