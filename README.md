# Kevin Chiwera — Portfolio

Static portfolio plus the included OpsDesk demo, ready for GitHub Pages.

## Contents

- `index.html` — portfolio home page.
- `assets/` — portrait and Nova Insurance / V2G screenshots.
- `opsdesk/` — the working fictional IT operations demo linked from the portfolio.

## Publish with GitHub Pages

1. Create a new public GitHub repository, for example `kevin-chiwera-portfolio`.
2. Extract this package and upload the *contents* of this folder to the repository root. Keep `assets` and `opsdesk` folders in place.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Your portfolio URL will be `https://chiwerak-oss.github.io/kevin-chiwera-portfolio/`. The OpsDesk project opens at the relative `/opsdesk/` path.

Everything is public after publishing. OpsDesk has fictional demo data only; do not add real company details or credentials.
